# アップデートとバージョン管理: OpenClaw vs ZeroClaw

*作成日: 2026-03-24*

## 動機

ZeroClawを選定したが、運用開始後のアップデートはどうなるのか？
Homebrewでインストールすればアップグレードも簡単なのか、セルフアップデート機能はあるのかを整理する。

## ZeroClaw のアップデート仕組み

### インストール方法

ZeroClawは複数の方法でインストールできる。

- **Homebrew**: `brew install zeroclaw`（core formulaeに収録済み。tapは不要）
- **Cargo（Rust）**: `cargo install zeroclaw`
- **ブートストラップスクリプト**: `curl -fsSL https://raw.githubusercontent.com/zeroclaw-labs/zeroclaw/main/scripts/bootstrap.sh | bash`
- **プリビルトバイナリ**: `./bootstrap.sh --prefer-prebuilt`
- **ソースビルド**: `cargo build --release --locked` → `cargo install --path . --force --locked`

### アップグレード

- **Homebrew経由**: `brew upgrade zeroclaw` — 一番シンプル
- **セルフアップデート**: v0.5.0で `update` コマンドが追加された。6フェーズのパイプラインとロールバック機能を持つ
- **Cargo経由**: `cargo install zeroclaw` で上書きインストール
- **ソースビルド**: git pull → cargo build --release

### バージョン管理

- GitHubのタグ付きリリース（v0.5.0, v0.6.1 など）
- 設定ファイルは `~/.zeroclaw/config.toml`（ホットリロード対応）
- 最新バージョンは v0.6.1（デスクトップコンパニオンアプリ・デバイス対応インストーラー含む）

## OpenClaw のアップデート仕組み（比較用）

### インストール方法

- **npm**: `npm install -g openclaw@latest`
- **Homebrew CLI**: `brew install openclaw-cli`
- **Homebrew macOS App**: `brew install --cask openclaw`（macOS 15+）
- **ワンライナースクリプト**: macOS向け。Node検出とオンボーディングウィザード付き
- **ソースビルド**: clone → `pnpm install` → `pnpm build`

### アップグレード

- **セルフアップデート**: `openclaw update` コマンドが充実。`--dry-run`（プレビュー）、`--timeout`（タイムアウト設定）フラグあり
- **リリースチャンネル**: stable / beta / dev の3チャンネル。`openclaw update --channel stable|beta|dev` で切り替え可能
- **更新頻度**: 週次レベルで頻繁にリリースされる
- **スキーマ変更**: バージョン間でスキーマ変更があると問題が出ることも。`doctor --fix` で自動修復を試みる

### プラグイン・スキル管理

- **ClawHub**: 公式スキルレジストリ。`openclaw skills search|install|update` で管理
- **プラグイン**: `openclaw plugins install clawhub:<package>` でインストール。コンテンツハッシュによる更新検知

## 比較まとめ

| 観点 | ZeroClaw | OpenClaw |
|------|----------|----------|
| Homebrew | `brew install zeroclaw`（core） | CLI: `brew install openclaw-cli` / App: cask |
| セルフアップデート | v0.5.0+ で対応（ロールバック付き） | `openclaw update`（チャンネル切替・dry-run対応） |
| 言語/ランタイム | Rust（バイナリ配布、Nodeは不要） | Node.js 22.16+（npm配布） |
| リリース頻度 | タグ付きリリース（不定期） | 週次レベル（YYYY.M.D形式） |
| リリースチャンネル | なし（GitHubリリースのみ） | stable / beta / dev |
| プラグイン管理 | — | ClawHub（スキル・プラグインレジストリ） |

## M4 Mac Mini での推奨

Homebrewで入れて `brew upgrade zeroclaw` で更新するのが一番楽。理由は以下の通り。

- Rustのビルド環境を用意する必要がない
- Homebrewが依存関係を管理してくれる
- `brew upgrade` を日常的に実行していれば他のツールと一緒にアップデートできる

ZeroClaw v0.5.0以降なら `zeroclaw update`（セルフアップデート）も使えるが、Homebrewと競合する可能性があるため、**どちらか一方に統一したほうがいい**。Homebrewでインストールしたなら、Homebrewでアップデートする。

## 気になる点

- ZeroClawの `update` コマンドとHomebrewの `brew upgrade` を併用するとバージョン不整合が起きないか？ → Homebrew管理に統一するのが無難
- ZeroClawにはリリースチャンネル（beta/dev）がない。OpenClawほど頻繁なリリースではないので、安定版を追うだけでよさそう
- OpenClawのスキーマ変更問題はZeroClawでも起き得るか？ → ZeroClawはTOML設定でホットリロード対応なので、影響は小さいと思われるが要確認
