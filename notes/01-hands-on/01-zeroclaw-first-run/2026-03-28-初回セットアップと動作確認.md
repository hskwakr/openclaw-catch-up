# ZeroClaw 初回セットアップと動作確認

*日付: 2026-03-28*

## 環境

- Mac Mini M4 16GB（対象マシン）
- MacBookからSSHでアクセスして作業

## インストール

```bash
brew install zeroclaw
brew install --cask codex
```

## オンボーディング

```bash
zeroclaw onboard
```

設定結果（`~/.zeroclaw/config.toml` に保存）:

| 項目 | 設定値 |
|------|--------|
| Provider | openai-codex |
| Model | gpt-5-codex |
| Autonomy | Supervised |
| Memory | sqlite (auto-save: on) |
| Channels | Cli, Discord |
| API Key | not set (env var or configで設定) |
| Tunnel | none (local only) |
| Composio | disabled (sovereign mode) |
| Hardware | disabled (software only) |

## Codex OAuth認証

```bash
zeroclaw auth login --provider openai-codex --device-code
```

- ブラウザからのログイン自体は成功
- SSHセッション経由だったためか、デバイスコードフローのフォールバックがうまくいかなかった
- zeroclaw側がタイムアウトした後、URLを手動で渡すフォールバックコマンドを実行して解決
  - **TODO**: フォールバックコマンドの正確な書式をメモしておく（次回のために）

## 動作確認

```bash
zeroclaw channel start
```

Discord経由での動作確認に成功。

## 残課題・気になること

- **Discord Bot権限**: 設定した権限が厳しすぎる可能性がある。問題が起きたら見直す
- **Discord Bot作成手順の振り返り**: 何を設定したか別セッションで整理予定（Developer Portal側の設定、Intent、権限など）
- **認証フォールバック**: SSHセッションでのdevice-codeフローの手順を正確に記録しておきたい
