# OpenClaw コミュニティ動向

*2026-03-21 作成*

## ガバナンスと財団移管

- 2026/2/14、Steinberger が OpenAI 参加を発表すると同時に、プロジェクトを独立した **501(c)(3) 財団** に移管する方針を表明
- OpenAI がバックアップする形で、より多くのモデル・企業をサポートする体制を目指す
- ただし **ガバナンス憲章はまだ未公開** — 意思決定プロセスの透明性に懸念が残る
- OpenAI が関与することで、セキュリティ判断が技術的メリットだけでなく商業的考慮に影響されるのでは、という疑問も

## コミュニティの集まる場所

| チャネル | 用途 |
|---------|------|
| **Discord** | メインのコミュニティハブ。#help, #users-helping-users, #models など |
| **GitHub Issues / Discussions** | 技術的な議論、バグ報告、PR |
| **CoClaw (coclaw.com)** | コミュニティフォーラム（Q&A、トラブルシューティング） |
| **公式ブログ (openclaw.ai/blog)** | アナウンス、リリースノート |
| **GitHub - openclaw/community** | Discord のポリシー・ドキュメント管理 |

→ **セットアップ時に使えるリソース**: Discord の #help と CoClaw が実用的。GitHub Issues はバグ調査に。

## エコシステム

### ClawHub（スキルレジストリ）
- **5,700〜13,700+ のサードパーティスキル**（情報源により幅あり）
- 2026/2 から VirusTotal による自動スキャンを導入（悪意あるスキルのブロック）

### 注目フォーク・派生プロジェクト
- **NanoClaw** — コンテナ分離型、Anthropic Agents SDK ベース、WhatsApp ネイティブ連携
- **Nanobot** — 超軽量（Python 約4,000行、OpenClaw の 1%）
- **PicoClaw** — 速度・シンプルさ重視の軽量フォーク
- **N8n-claw** — n8n ワークフロー自動化との統合

### 連携プラットフォーム
- メッセージング: WhatsApp, Telegram, Discord, Slack, WeChat Work, Feishu/Lark
- ビジネスツール: Stripe, Shopify, WordPress, Google Ads, CRM 各種
- エンタープライズ: NVIDIA NemoClaw（セキュリティ・ガバナンス層）

## 企業の関与

- **OpenAI** — 財団のバックアップ
- **NVIDIA** — NemoClaw でエンタープライズ向けセキュリティ制御を提供
- **Composio** — 1,000+ ツール連携のノーコード統合
- **Tencent** — WeChat 向け OpenClaw ベース製品群（ClawBot）を発表（2026/3/22）
- **ManagedClaw** — 導入コンサルティング（50+ のビジネス展開実績）

## 論争・懸念事項

### 商標問題と詐欺
- Anthropic からの商標指摘で Clawdbot → Moltbot → OpenClaw と2回改名
- 改名の間に元の @clawdbot アカウント（6万フォロワー）が乗っ取られ、偽暗号通貨 "$CLAWD" の宣伝に悪用された

### サプライチェーン攻撃
- **ClawHavoc 攻撃（2026/2）** — 初期発見で341の悪意あるスキル、その後の調査で824+に拡大。暗号通貨ツールを装ったマルウェア
- **GitHub フィッシング（2026/3/18）** — OpenClaw 開発者をターゲットに「$5K エアドロップ」を餌にしたフィッシング
- → **スキルのインストール時は信頼性の確認が必須**

### Anthropic との摩擦
- Claude Pro サブスクリプションを OpenClaw 経由で利用するユーザーを Anthropic がブロック
- 後に「公式の統合は許可、非公認の第三者アクセスは不可」と明確化

### 政府の制限
- **中国**: 政府機関・国有企業での使用を制限
- **韓国**: 複数の大手テック企業が社内利用を禁止

### GitHub スターの信憑性
- 2ヶ月で 25万スターは本当の採用を反映しているのか、ボット駆動のハイプなのか議論あり
- 1日で 25,000 スター超のジャンプが複数回 — スクリプトの可能性（未確認）

### ライセンスのリスク
- MIT ライセンスは商用利用時の包括的な責任保護を提供しない
- エンタープライズ展開には注意が必要

## セットアップに向けての示唆

この調査から、次にセットアップを行う際に意識すべきポイント:

1. **スキルの信頼性** — ClawHub からのインストールは VirusTotal スキャン済みとはいえ慎重に。公式・人気のあるスキルから始める
2. **情報源** — Discord #help、CoClaw、GitHub Issues が実用的な情報源
3. **セキュリティ情報** — NVIDIA NemoClaw のアプローチ、Lakera や HKCERT のセキュリティ分析が参考になる
4. **軽量代替案** — NanoClaw や PicoClaw も検討の余地あり（セキュリティ面でシンプルな方が安全かも）
