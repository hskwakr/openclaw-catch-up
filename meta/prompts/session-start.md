# セッション開始プロンプト

## 用途

新しいCoworkセッションを始めるとき、このフォルダを選択した上で以下のプロンプトを貼る。
Coworkプロジェクトのインストラクションに設定してもOK。

---

## プロンプト

```
OpenClawのキャッチアップを一緒に進めています。

まず以下のファイルを読んで、現在の状況を把握してください：
1. PROGRESS.md — 今どこにいるか、次にやること
2. meta/001-folder-structure.md — フォルダ構成のルール

その上で、前回の続きから再開するか、新しいトピックに取り組むか提案してください。

ノートの作成・更新時はフォルダ構成ルールに従ってください。
学習が進んだらPROGRESS.mdを更新してください。
```
