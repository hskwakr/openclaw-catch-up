# PROGRESS見直し プロンプト

## 用途

PROGRESS.mdが肥大化・陳腐化していないかを定期的にチェックするとき使う。
大きなトピックが完了したタイミングや、セッションの冒頭で実行するのが理想。

---

## プロンプト

```
PROGRESS.mdを見直してください。

PROGRESS.mdの役割は「再開のエントリーポイント」です。
「今どこにいて、次に何をするか」がすぐにわかることが最優先。

以下の観点でチェックし、必要があれば修正を提案してください:

1. 決まっていないこと → 決まったこと
   - 実質的に結論が出ているものを「決まっていること」に移す

2. まだ気になっていること → 解決済み
   - 調査やIssueの進展で解消された懸念を除去する

3. 次にやることの優先順位
   - 状況の変化で優先順位が変わっていないか？
   - 完了した項目が残っていないか？
   - 具体的なアクションとして実行可能か？

4. 肥大化チェック
   - 完了済みで今は参照不要な情報が本文に残っていないか？
   - 溜まった解決済み項目は meta/progress/ に退避する

5. ノート一覧の整合性
   - 新しく作成したノートがリストに反映されているか？
   - リンク切れがないか？

修正したら最終更新日を更新してください。
```

---

## 使い方のコツ

- セッション冒頭でPROGRESS.mdを読んだ直後に実行するのが自然
- ファクトチェックプロンプトと組み合わせると効果的
