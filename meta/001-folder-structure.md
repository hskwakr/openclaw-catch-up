# ADR-001: フォルダ構成ルール

*決定日: 2026-03-21 / 更新: 2026-03-25*

## 背景

OpenClawのキャッチアップを進める中で、学習ノートが散らばらないように構成ルールを定めておく。
一人で進めると途中で止まりがちなので、「どこに何があるか」を明確にして再開しやすくする。

## 全体構成

```
openclaw-catch-up/
├── PROGRESS.md              # エントリーポイント（今ここ・次にやること）
├── meta/                    # 合意事項・運用ルール・メタ的な管理情報
│   ├── 001-folder-structure.md
│   ├── progress/            # PROGRESS.mdから退避した過去ログ
│   │   └── YYYY-MM.md
│   ├── prompts/             # セッション開始時などに使うプロンプト
│   │   ├── session-start.md
│   │   ├── fact-check.md
│   │   └── progress-review.md
│   └── ...
└── notes/                   # 学習ノート
    ├── 00-pre-research/     # 完了したフェーズをまとめたフォルダ
    │   ├── README.md        # フェーズのサマリー
    │   ├── 01-overview/
    │   ├── ...
    │   └── 11-setup-guide/
    ├── {NN-topic-folder}/   # 現在進行中のトピックフォルダ
    │   └── YYYY-MM-DD-タイトル.md
    └── YYYY-MM-DD-タイトル.md  # 未分類ノート
```

## ルール

### PROGRESS.md（ルート直下）

- **役割: 再開のエントリーポイント**
- 「今どこにいて、次に何をするか」がわかることが最優先
- 含めるもの: 現在地、気になっていること、ノートへのリンク
- **含めないもの: 完了済みで今は関心のないトピックの詳細**
- 肥大化したら過去の記録を `meta/progress/` に移す

### meta/progress/（過去ログ）

- PROGRESS.mdから溢れた完了記録の退避先
- ファイル名: `YYYY-MM.md`（月別）など、量に応じて決める
- 「あのとき何を学んだっけ？」と振り返りたいときに参照する

### ノートの置き場所

1. **トピックフォルダ**
   - フォルダ名: `NN-トピック名`（例: `01-overview`, `12-setup-log`）
   - ノートのファイル名: `YYYY-MM-DD-タイトル.md`

2. **フェーズが完了したらまとめる**
   - 完了したフェーズのフォルダ群を `00-フェーズ名/` のようなラッパーフォルダに移動
   - ラッパーフォルダに `README.md`（サマリー）を置く
   - 個別ノートの内部構造はそのまま維持

3. **分類しにくいものは `notes/` 直下でもOK**
   - 雑多なメモ、ふと浮かんだ疑問などはフォルダに入れなくてもいい

### meta/ フォルダ

- 学習内容ではなく、**進め方に関する合意事項やメタ的な管理情報** を置く
- ADR: `NNN-タイトル.md`（連番）
- サブフォルダ: 必要に応じて切る（例: `progress/`, `prompts/`）

### meta/prompts/（プロンプト）

- セッション開始時やファクトチェック時に使うプロンプトを管理する
- 使いながら改善メモを追記し、プロンプト自体を育てていく

## 今後変更がありうる点

- ノートのテンプレートを定めるか（現時点では未定）
- タグやカテゴリの仕組みが必要になるか
- PROGRESS.mdから過去ログへの退避タイミングの基準
- meta/ に他にどんな合意事項が増えるか
